# Python File Automation Tool

This project automatically organizes files into folders based on file type.

## Features
- Organizes files automatically
- Creates folders if missing
- Saves manual effort

## Technologies
- Python 3
- pathlib
- shutil

## How to Run
1. Create a folder named `downloads`
2. Place files inside it
3. Run:
   python file_organizer.py
